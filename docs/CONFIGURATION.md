# 配置参考

运行配置保存在项目根目录 `.env`。公共样例见 [.env.example](../.env.example)，不同厂商的模型配置见 [模型目录](../config/models/README.md)。

## 公共参数

| 参数 | 用途 / 默认值 |
| --- | --- |
| `QQ_APP_ID`、`QQ_APP_SECRET` | 手动模式填写；扫码模式留空，由绑定数据卷提供 |
| `INTERNAL_API_TOKEN` | Gateway 与 Worker 通信令牌，至少 32 字符；初始化命令生成 64 位十六进制字符串 |
| `ADMIN_API_TOKEN` | Worker 管理 API 令牌，至少 32 字符且不同于内部令牌；默认留空关闭接口 |
| `COMPOSE_PROJECT_NAME` | 同机多实例各用独立项目名，保持稳定以复用各自数据卷 |
| `QQ_OBSERVE_GROUP_MESSAGES` | 默认 `false`；获得 QQ 对应权限后才能接收所有群消息 |
| `GATEWAY_PORT` | 健康检查端口，默认 `18700`，仅监听本机 |
| `WORKER_PORT` | 健康检查和管理 API 端口，默认 `18710`，仅监听本机 |
| `MAX_CONCURRENCY` | 并发处理上限，默认 `4`，范围 1～16 |

默认处理收到的群 @ 和私聊事件。Gateway 健康检查要求 QQ 已连接；连接失败时 Worker 会等待。检查机器人凭据、QQ 权限、IP 白名单与网络。

## 可选工具

| 功能 | 配置 |
| --- | --- |
| 图片生成／编辑 | `IMAGE_BASE_URL`、`IMAGE_API_KEY`、`IMAGE_MODEL` 三项齐全 |
| 语音 | `SPEECH_BASE_URL`、`SPEECH_API_KEY`、`SPEECH_MODEL` 三项齐全；`SPEECH_VOICE` 默认 `alloy` |
| 搜索 | `SEARXNG_URL` 指向启用 JSON 输出的 SearXNG |

图片与语音使用 OpenAI 兼容协议，具体模型和能力由接入服务决定。只填写图片或语音的一部分必填项会导致配置检查失败；不需要时全部留空。语音没有内置 Edge TTS 实现。

网页读取只访问公开 HTTP(S) 地址，拒绝本地网络和保留地址；遇到 403 明确返回失败，同轮相同请求不重试。

## 记忆与状态

- 世界书保存长期事实，支持常驻或中文关键词触发、启停、优先级和字符预算。
- 群规则每轮注入，相当于当前角色的作者注释。
- 摘要在每 3 个已完成回复轮次或空闲 2 分钟后生成，后台每 15 秒检查。失败保留旧摘要，2 分钟后重试。
- 个人记忆只加载当前会话、当前角色下的当前发言成员内容。成员以稳定标识区分，不依赖昵称。
- 明确说“记住……”才保存长期内容；普通聊天不会自动抽取长期事实。复杂表达使用命令设置。
- 角色状态由模型按需提交更新，正常回复发送成功后才保存；旁听消息与查询指令不计分。

QQ 手动修改按六个命令组控制，新部署及升级后全部默认关闭。权限通过管理 API 修改并保存在当前实例 SQLite，重启保留；开放后对该实例所有会话成员生效，不影响其他实例。普通聊天、只读查询、模型自动状态更新及后台摘要不受开关影响。自然语言记忆、撤销、导入和延迟保存均检查对应权限。

成员只能查询、修改自己的个人数据；在群内查询的结果仍会发送到群中。角色改名不会删除历史。`/重置上下文` 保留状态和长期记忆。管理 API 的直接配置使用独立审计身份，不受 QQ 开关限制。详见 [管理 API](ADMIN_API.md) 和 [多实例部署](DEPLOYMENT.md#同机部署多个实例)。

完整语法见 [QQ 命令说明](COMMANDS.md)。

## 运行限制

- 单次模型调用最长 180 秒，输出上限 32768 token，包含推理 token。
- 整轮处理期限 285 秒，并预留发送时间；图片生成使用剩余时间。
- 每轮最多 12 次模型调用、24 次工具执行；搜索最多 3 次、网页读取最多 6 次，生图／编辑／语音各最多 1 次。
- 文本按 1800 字分段，群消息最多 5 次被动回复，私聊最多 4 次，媒体也占一次。超长文本会标记截断。
- 当前二进制媒体上限 5 MiB，不支持大文件分片上传。
- 标准 JSON 导入文件上限 8 MiB，单批最多 100 个角色；先预览，10 分钟内确认。详见 [导入说明](IMPORT.md)。
- 发送前持久化去重；发送结果不确定时不自动重发，极端情况下可能少回复一次。

上下文按完整工具轮次裁剪，Responses 加密推理仅在同模型回放。QQ 回复不包含内部推理。

## 日志排查

Worker 失败日志记录 `error_kind`、`http_status`、模型、协议和档位，不输出 API Key、聊天内容或上游响应正文。

| 日志信息 | 检查方向 |
| --- | --- |
| `401/403` | 鉴权、账号与模型权限 |
| `404/405` | 基础地址与调用协议 |
| `400` | 模型、工具支持、输出上限与思考参数 |
| `error_kind=transport` | 网络与传输问题 |

日志中的 `reasoning_tokens_subset` 已包含在 `output_tokens` 内，不要重复相加。查看日志与更新配置的命令见 [部署与维护](DEPLOYMENT.md)。
