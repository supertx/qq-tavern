# QQ 命令与记忆行为

在群里先 @ 机器人，再输入命令；私聊直接输入。命令与参数之间使用空格。以下名字、编号和记忆内容都是演示数据。

## 生效范围

- 群设置按「机器人＋群＋角色档案」隔离。任何当前群成员都可以修改公共设置、创建和切换角色；切换对全群生效。
- 个人记忆再按 QQ 成员标识隔离，不以昵称识别人。同一个人在两个群里的个人记忆也独立。
- 私聊是独立会话。命令没有跨群目标参数，私聊不能管理群记忆。
- `/记忆` 只能读取和修改发起者自己的记录。命令回复会发送到当前会话：在群内查询，查询结果也会发到群里；这不等同于私密消息功能。
- 保存成功后下一轮普通对话生效。已开始的一轮使用启动时的设置快照。
- 模型、思考强度、接口地址和密钥由部署者配置；群成员不能通过这些命令改变共享服务配置。

## 从这里开始

| 命令 | 用途 |
| --- | --- |
| `/酒馆` | 查看帮助、当前角色、配置版本和世界书条目数量 |
| `/当前模型` | 查看当前模型、思考强度和调用协议 |
| `/记忆状态` | 查看保存数量、字符预算，以及自己上一轮普通对话的世界书注入情况 |
| `/修改记录` | 最近 10 条公共修改与自己的个人修改，包含操作者、版本和 UTC 时间 |
| `/撤销修改 12` | 撤销编号 12 的修改；只允许撤销对应设置的最新版本 |

角色、群规则和世界书共享一个公共配置版本。它们任一项有后续修改，较早版本的撤销会被拒绝，以免覆盖后续修改。个人记忆和摘要使用各自版本；其他成员的个人修改不出现在自己的修改记录中，也不能通过猜测编号撤销。

## 角色和群规则

```text
/角色
/角色 名称 星灯
/角色 描述 守护山间书屋的向导
/角色 性格 温和、认真，喜欢用实例解释问题
/角色 场景 大家正在书屋筹备周末活动
/角色 清空

/群规则
/群规则 设置 每次回复使用简体中文，结尾加一句“愿你今天顺利”。
/群规则 添加 涉及群活动时先说明时间和地点。
/群规则 清空
```

`设置` 替换原内容，`添加` 追加一行。群规则相当于当前角色的作者注释，每轮注入。改名或 `/角色 清空` 不会删除档案、聊天历史、记忆或状态；清空只移除人设内容，档案名仍保留。私聊同样可以配置多个独立角色。

## 多角色档案

```text
/角色 列表
/角色 新建 丛雨
/角色 切换 丛雨
/角色 名称 丛雨大人
```

新建会立即切换到空白档案，自带三个默认状态项，不复制其他角色的人设、世界书或聊天记录。角色名在本会话内唯一，最长 100 字，可包含空格但不能换行。改名不改变档案标识。现有数据库升级后保留原角色名；未命名时档案名为“默认角色”。没有跨会话角色管理指令。

世界书、群规则、个人记忆、摘要、历史搜索、注入记录、修改记录和撤销都跟随角色切换。`/重置上下文` 只清除当前角色的历史和摘要，保留状态及长期记忆。进行中的聊天和摘要绑定开始时的角色；先被观察、后被回复的同一 QQ 消息也保留原角色归属。

## 角色状态与好感度

```text
/角色状态
/角色状态 丛雨
/好感度
/好感度 丛雨
/状态记录
/状态设置 好感度 30
/状态重置 好感度
```

查询指定角色不会切换当前角色。查询直接读取保存值，不消耗模型调用。默认好感度 20，范围 0～100，每轮最多增减 3；关系初始“尚未建立”，两者均对每位成员独立保存。心情初始“平静”，由角色共享。文本状态最多 200 字。旧历史不会追溯计算状态。

普通回复不附带状态栏，状态用于影响角色态度和剧情。模型在需要时调用内部工具提交一份变化建议，程序验证项目、类型、归属、范围和增减幅度；同轮重复调用或重复消息不重复计分。达到数值边界时只变化到边界。模型或发送失败、发送结果不确定时不保存更新。工具调用可能增加一次后续模型请求，但不会固定在每轮结束后再调用独立评估模型。

手动设置仍须满足数值范围或文本长度，不受自动更新的单轮增减上限限制。重置单个项目恢复当前配置的初始值。成员项目只操作自己；角色共享项目的修改对全群生效。仅观察到的消息、查询和设置指令不自动推进好感度。

`/状态记录` 显示当前角色最近 10 条共享变化与自己的成员变化，包含前后值、简短原因和修订编号。`/修改记录` 也包含状态和定义修改。`/撤销修改 编号` 只能撤销对应状态组的最新版本：共享项目是一组，每位成员的项目各为一组。自动更新同时改变共享项与成员项时产生两条修订，分别撤销。撤销若违反当前状态定义的范围会被拒绝。

## 自定义状态项

```text
/状态项
/状态项 添加 信任度 数值 成员
/状态项 设置 信任度 初始值 10
/状态项 设置 信任度 范围 0 100
/状态项 设置 信任度 单轮上限 3
/状态项 设置 信任度 规则 遵守承诺时增加，欺骗时降低
/状态项 添加 体力 数值 角色
/状态项 设置 体力 初始值 100
/状态项 添加 当前地点 文本 角色
/状态项 设置 当前地点 初始值 神社
/状态项 停用 信任度
/状态项 启用 信任度
```

每个角色最多 32 项，名称 1～32 字且不含空白。支持“数值／文本”和“成员／角色”两种归属组合。新数值项默认初始 0、范围 0～100、单轮增减上限 3；新文本项默认“未设定”。更新规则最多 600 字。

初始值修改只影响尚未保存的项目与后续重置，不覆盖现有值。调整范围必须同时容纳初始值和所有已保存值，否则提示先校正。类型和归属不能直接改变，需要另建项目。停用保留值和历史，暂停普通查询展示、上下文注入和自动更新；仍可手动校正或重置。已有保存值的项目不能通过撤销定义添加来删除，应使用停用。

## 世界书

```text
/世界书
/世界书 列表 2
/世界书 添加 常驻 活动时间 | 本群读书会在每周五晚上八点进行。
/世界书 添加 关键词 苹果,果园 | 果园安排 | 周末果园集合地点是南门。
/世界书 查看 1
/世界书 修改 1 本群读书会改到每周六晚上八点。
/世界书 关键词 1 读书会,活动
/世界书 关键词 1 常驻
/世界书 优先级 1 80
/世界书 关闭 1
/世界书 开启 1
/世界书 删除 1
/世界书 预算 6000
/世界书 清空 确认
```

新条目默认启用、优先级 50。`|` 是添加命令的字段分隔符，添加时内容不要再包含 `|`；需要时可以随后用 `修改` 设置正文。关键词可以用英文或中文逗号分隔。

- 常驻条目每轮参与注入选择；关键词条目匹配**当前消息正文**，任一关键词命中即可，不递归扫描其他条目、不随机触发。
- 匹配不区分字母大小写，中文使用子串匹配，不要求英文式单词边界；不支持正则表达式。
- 优先级越高越先分配预算；相同优先级按条目编号排序。单条放不下时跳过该条，继续判断后续条目。
- 预算使用 Unicode 字符数，包含条目的注入标签和分隔文字，**不是 token 数**。只限制世界书部分，不包括角色、群规则、个人记忆、摘要或聊天历史。
- `预算 0` 暂停全部世界书注入，记录仍保留。
- `已保存` 不保证模型每次提及该内容。`/记忆状态` 区分「已注入」「已停用」「关键词未命中」「字符预算不足」，报告的是自己上一轮普通对话的选择结果。

`/世界书 列表` 每页 10 条；用 `/世界书 查看 编号` 查看完整正文。`/群记忆 [页码]` 同时显示本群规则和世界书摘要，每页 10 条、每条最多显示 300 字符；完整规则用 `/群规则` 查看。

## 明确要求记住

```text
/记住 本群每周五举办读书会。
/记到群 小林负责本次活动的签到。
记住，以后每次回复结尾加一句“收到”。
请记住，回复我时用简短句子。
```

群内明确保存的事实默认进入公共世界书，作为启用的常驻条目。`每次回复`、`每轮回复`、`每次回答`、`每轮回答`、`每次对话`、`每轮对话`、`回答末尾`、`回复末尾` 等表达进入公共群规则，对本群所有成员生效。

包含 `我的偏好`、`回复我时`、`回答我时`，或以 `我喜欢`、`我不喜欢`、`我叫` 开头的保存内容，进入发起者在本会话的个人记忆。个人指向优先于公共回复规则。`/记到群` 强制选择本群公共范围；私聊拒绝该命令。私聊的一般事实进入个人记忆，回复规则进入该私聊的规则。

自然语言入口仅识别开头明确的 `请帮我记住`、`帮我记住`、`请记住`、`记住`、`记一下`，以及 `以后每次回复`、`以后每轮回复`。它不是完整自然语言意图解析器；表达复杂时使用明确命令。普通聊天不会自动提取长期事实，后台摘要也不会写入世界书或个人记忆。

## 个人记忆

```text
/记忆
/记忆 设置 我喜欢简短回答，不使用表情符号。
/记忆 清空
```

`设置` 替换当前成员的整段个人记忆。自然语言保存或 `/记住` 的个人内容追加一行。改变个人记忆不会影响其他成员，也不会改变同一成员在其他群的记录。

## 聊天摘要和上下文

```text
/摘要
/摘要 更新
/摘要 设置 活动地点已确定为南门，集合时间尚未决定。
/摘要 清空
/重置上下文
```

摘要默认在至少 3 个完成回复的轮次后，或未总结对话空闲 2 分钟后，由后台检查触发。仅观察到的群消息不计入「3 个完成轮次」，但可在空闲时参与摘要。后台轮询、排队和模型耗时会让实际更新时间晚于阈值。摘要模型使用固定 `medium` 强度，失败保留原摘要。

`/摘要 更新` 整理检查点之后的对话；没有新对话时不重新生成。`设置` 或 `清空` 将当前历史末尾作为新的摘要检查点，后续自动摘要从此处继续。历史摘要可能遗漏或误写信息，可以手动修正；它与长期记忆分开保存。

`/重置上下文` 清除本会话聊天历史与摘要，保留角色、群规则、世界书和所有成员个人记忆。上下文重置不能通过 `/撤销修改` 恢复。世界书删除、群规则清空、个人记忆清空与手动摘要修改仍有版本记录，可在没有后续同类修改时撤销。

## 首版限制

| 项目 | 限制 |
| --- | --- |
| 角色名称 | 100 字符 |
| 角色描述＋性格＋场景 | 合计 12000 字符 |
| 群规则／作者注释 | 6000 字符 |
| 世界书 | 每会话最多 200 条 |
| 条目标题／正文 | 100／6000 字符 |
| 关键词 | 每条最多 20 个，每个最多 100 字符 |
| 优先级 | 0–100，默认 50 |
| 世界书预算 | 0–24000 字符，默认 6000 |
| 个人记忆 | 每成员每会话 6000 字符 |
| 手动摘要 | 16000 字符；自动摘要提示目标为 3000 汉字 |

首版不提供角色卡导入、向量检索、SillyTavern 插件、复杂宏或完整预设兼容。QQ 是否投递未 @ 的群消息取决于机器人权限，未收到的消息无法被记录或总结。
